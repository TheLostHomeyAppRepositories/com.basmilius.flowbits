# FlowBits for Homey

FlowBits adds reusable state and logic to Homey Flows. Keep track of a mode, remember that something happened, or share a timer between automations without rebuilding the same logic in every Flow.

## Building blocks

| Tool | Purpose |
| --- | --- |
| Sequences | Move forward or backward through numbered steps |
| Flags | Track on/off states, optionally with an expiration |
| Modes | Represent situations such as being home or watching a film |
| Sets | Group states and activate them individually, together or exclusively |
| Labels | Store text values for use across Flows |
| Events | Record occurrences and check their timing or count |
| No-repeat windows | Prevent repeated execution within a time window |
| Timers | Start, pause, resume and repeat timed actions |
| Sliders | Store and adjust numeric values |
| Signals | Send named messages between Flows, optionally with a value |

Additional cards cover arithmetic, chance, date-related conditions and other utilities. Dashboard widgets provide controls for flags, modes, sets, labels, events, timers and sliders.

For example, activate a movie mode to coordinate several Flows, use a flag to temporarily disable notifications, or add a no-repeat window to a motion notification.

## Project structure

The app targets local Homey version 12.4 or newer. Runtime services live in `src/brain/`, Flow cards in `src/flow/`, and supporting data in `src/data/`. The Vue settings interface is in `settings-ui/`; dashboard widgets are in `widgets/`.

The [documentation source](docs/) contains the detailed user guide. Run `bun run docs:dev` from the repository root to preview it locally.

## Development

Use Bun for dependencies and scripts. Run these commands from the repository root:

```sh
bun install
bun run build
bun install --cwd settings-ui
bun run --cwd settings-ui build
```

Edit Homey metadata in `.homeycompose/` and driver compose files where present. The root `app.json` is generated by Homey. `README.txt` and its translations contain the Homey App Store description; this Markdown file documents the GitHub project.
